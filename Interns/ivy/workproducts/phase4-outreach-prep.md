## 1. CRM Pipeline Stages

Set these stages in Twenty CRM (or Apollo sequences):

| Stage | Definition | Auto-trigger |
|-------|------------|-------------|
| **Prospect** | Contact imported, no outreach yet | Initial CSV import |
| **Contacted** | Email 1 sent | After send |
| **Replied** | Any non-autoreply response | Manual or inbox rule |
| **Call Booked** | Discovery call scheduled | Calendly/calendar link |
| **Signup** | Demo done, trial started | CRM status update |

### Recurring Follow-Up View

Create a saved filter in Twenty CRM:

```
Stages: Contacted OR Replied
AND Last activity: > 3 days ago
AND No upcoming task
→ Shows stalled contacts that need a nudge
```

Refresh weekly. Purpose: pull contacts who went quiet after any touch into a "needs follow-up" queue.

## 6. Deliverability Basics

| Rule | Why |
|------|-----|
| **Send from ivy@msg2ai.xyz** | Consistent sender, domain warmed up |
| **No spammy words** | Avoid "free," "guaranteed," "act now," "limited time," all caps |
| **Plain text preferred** | Lower spam score than HTML-heavy |
| **One link max per email** | Calendar link or demo link, never both |
| **No images** | Images trigger spam filters on cold domains |
| **Send in batches of 10–15/day** | Avoids bulk flags; spread over 2–3 hours |
| **Warm the inbox first** | Send 5–10 internal/non-campaign emails/day for 1 week before blasting |
| **Track bounces** | Remove hard bounces immediately; soft bounces retry once |
| **Personalize {{first_name}} and {{company}}** | Merge tags reduce spam score vs generic |
| **Unsubscribe footer** | Include "Reply STOP to opt out" (complies with PH data privacy) |
