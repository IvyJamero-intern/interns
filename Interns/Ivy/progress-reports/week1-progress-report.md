## Key learnings

**What resonated in research:**
- Cost savings vs. global platforms is the #1 hook for Philippine event organizers
- Multi-channel support (Messenger + SMS + WhatsApp) is a differentiator — most competitors offer one or the other
- QR check-in automation resonates strongly with high-volume venues

**Objections anticipated:**
| Objection | Response |
|-----------|----------|
| We already use Facebook Messenger | Centralize Messenger, SMS, WhatsApp, and Viber in one platform |
| The solution seems expensive | Demonstrate ROI through reduced staffing and improved engagement |
| Our team is small | Automation minimizes manual communication tasks |
| We only host a few events each year | Flexible plans can scale based on event volume |
